# 증권사 앱 열기 버튼 — 짧은 설계

작성일: 2026-11-18 · 상태: 승인 대기 · 규모: 작은 변경

## 의도
청약 중인(또는 곧 청약할) 종목의 상세 화면에서, 그 종목의 주관 증권사 앱을 버튼 하나로 연다. 청약하러 갈 때 앱을 찾아 헤매지 않게 한다. 사용자는 안드로이드를 쓴다.

## 하지 않는 것
- 증권사 앱 안의 특정 화면(청약 화면)으로 바로 들어가기. 증권사들이 그런 주소를 공개하지 않는다.
- 아이폰 지원.
- 자동 청약, 로그인, 계좌 정보 다루기.
- 진짜 앱(APK) 포장. 다음 단계(2번)에서 따로 한다.

## 검토한 방법
1. **웹앱에 버튼 추가 (선택)**: 크롬의 `intent://` 링크로 앱을 연다. 가장 빠르고, 이후 2번(APK 포장)에서도 그대로 동작한다.
2. 웹앱을 APK로 포장: 사용자가 "일단 1번"을 골라 나중으로 미뤘다.
3. 새 안드로이드 앱: 지금 잘 되는 것을 다시 만드는 일이라 제외했다.

## 동작
- 상세 화면의 "청약" 줄 아래에 주관사마다 버튼을 둔다. 예: `유진투자증권 앱 열기`, `신영증권 앱 열기`. 버튼은 DESIGN.md의 weak 버튼(높이 38px, 연한 파랑)을 쓴다.
- 버튼은 청약이 끝나지 않은 종목(청약 마감일이 오늘 이후)에만 보인다. 끝난 종목은 증권사 앱을 열 이유가 줄어서다(작성자의 선택).
- **확인된 증권사(12곳)**: `intent://#Intent;package=<패키지명>;S.browser_fallback_url=<플레이스토어 주소>;end`. 앱이 있으면 앱이 열리고, 없으면 플레이스토어 앱 페이지가 열린다.
- **확인 못 한 증권사(하나, 신영, BNK, iM, 우리투자 등)**: 플레이스토어 검색 화면을 연다(`market://search?q=<증권사 이름>`). 패키지명을 추측하지 않는다.
- 안드로이드가 아닌 기기(PC 등)에서는 버튼 대신 "안드로이드에서 열 수 있어요"라는 안내만 보인다.

## 위험
- **크롬이 앱을 바로 열지 못하고 플레이스토어 앱 페이지를 띄울 수 있다.** 일부 앱은 외부 링크로 여는 것을 막아 두었기 때문이다. 이때는 플레이스토어의 "열기" 버튼을 한 번 더 눌러야 한다. 이 환경에서는 안드로이드를 시험할 수 없어서, **배포 후 사용자가 2~3개 증권사 버튼을 직접 눌러 확인**해야 한다. 안 되는 곳이 많으면 2번(APK 포장)에서 앱이 직접 실행하는 방식으로 해결한다.
- 증권사가 앱을 바꾸면 패키지명이 바뀐다. 그때는 표만 고치면 된다.

## 테스트
- `web/brokers.js`의 이름 정규화와 링크 생성은 `node --test`로 테스트한다(확인된 증권사는 intent 링크, 모르는 증권사는 검색 링크, 이름 변형 처리).
- 버튼 표시 조건(청약 마감 전, 안드로이드)은 화면에서 확인한다.
