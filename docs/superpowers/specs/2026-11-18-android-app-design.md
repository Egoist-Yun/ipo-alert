# 안드로이드 앱 (증권사 앱 직접 실행) — 짧은 설계

작성일: 2026-11-18 · 상태: 승인 대기 · 규모: 작은 프로젝트

## 의도
웹앱의 "증권사 앱 열기" 버튼을 누르면 크롬이 보안상 플레이스토어를 띄운다(사용자가 폰에서 확인). 지금 화면을 그대로 담은 안드로이드 앱을 만들어, 버튼을 누르면 증권사 앱이 **바로** 실행되게 한다.

## 하지 않는 것
- 화면 새로 만들기. 지금 GitHub Pages 화면을 그대로 쓴다.
- 플레이스토어 등록, 아이폰.
- 알림 방식 변경. 알림은 계속 ntfy 앱으로 받는다.

## 검토한 방법
1. **Capacitor로 감싸기 (선택)**: 앱 안의 웹 화면이 안드로이드 기능(앱 실행)을 직접 호출할 수 있다.
2. TWA(Bubblewrap): 내부적으로 크롬을 써서 지금과 똑같이 플레이스토어가 뜬다. 제외.
3. 지금 그대로 두기: 사용자가 1번을 골랐다.

## 동작
- 앱을 열면 `https://egoist-yun.github.io/ipo-alert/`를 앱 안에서 띄운다. 화면을 고치면 앱을 다시 설치하지 않아도 반영된다(작성자의 선택. 데이터와 화면이 항상 최신이다).
- 증권사 버튼:
  - **확인된 12곳**: 앱이 있으면 패키지명으로 **직접 실행**한다. 없으면 플레이스토어 앱 페이지(`market://details?id=<패키지>`)를 연다.
  - **모르는 곳**: 지금처럼 플레이스토어 검색 화면.
- 일반 브라우저(크롬)에서 열 때는 지금 동작(intent 링크)을 그대로 유지한다. 앱 안인지 아닌지는 Capacitor가 주입하는 `window.Capacitor`로 구분한다.
- 안드로이드 11 이상은 다른 앱의 설치 여부를 보려면 그 패키지를 앱 설정(`AndroidManifest.xml`의 `<queries>`)에 적어야 한다. 확인된 12개 패키지를 적는다.
- 앱 이름은 "공모주 달력", 아이콘은 지금 `web/icon.svg`를 PNG로 바꿔 쓴다.

## 만드는 방식 (작성자의 선택)
- `app/` 폴더에 Capacitor 프로젝트를 만든다. 앱 실행은 공식 플러그인 `@capacitor/app-launcher`를 쓴다.
- 이 컴퓨터의 Android Studio, 안드로이드 SDK, JDK로 빌드한다. 필요한 JDK 버전은 Capacitor 버전에 맞춘다(Android Studio에 들어 있는 JDK 사용 가능).
- **서명**: 개인용이라 디버그 서명으로 빌드한다. 키 관리가 필요 없다. 다만 앱을 업데이트할 때는 이 컴퓨터에서 빌드해야 한다(다른 컴퓨터의 디버그 키로 빌드하면 덮어쓰기 설치가 안 된다).
- **폰으로 옮기기**: 빌드한 APK를 GitHub 저장소의 "릴리스"에 올려서 폰에서 바로 내려받게 한다. 저장소가 공개라 누구나 받을 수 있지만, 들어 있는 건 공개 화면 주소와 공개 패키지명뿐이다. 원하지 않으면 USB나 메신저로 직접 옮긴다.

## 위험
- 증권사 앱이 직접 실행을 막는 경우는 드물지만 있을 수 있다. 사용자가 2~3개 증권사 버튼을 눌러 확인한다.
- `server.url`로 원격 화면을 띄우는 방식은 Capacitor가 "개발용"이라고 안내하는 방식이다. 인터넷이 없으면 화면이 안 뜬다. 개인용으로는 충분하다고 판단했다.

## 테스트
- 버튼이 어떤 동작을 할지 고르는 순수 함수(`brokerAction(name, isNativeApp)`)를 `node --test`로 테스트한다. 앱 안이면 패키지 실행, 아니면 intent 링크, 모르는 곳은 검색.
- APK 빌드가 성공하는지, 매니페스트에 12개 패키지가 들어갔는지 확인한다.
- 실제 실행은 사용자가 폰에서 확인한다.

## 구현 중 바뀐 점 (2026-11-18)
- 앱 실행에는 `android-app://` 주소가 아니라 **패키지명**을 그대로 넘긴다. `@capacitor/app-launcher`의 안드로이드 구현이 패키지명을 받아 실행하고, 앱이 없으면 예외 없이 `completed: false`를 돌려주기 때문이다. 그때 플레이스토어 앱 페이지를 연다.
- Capacitor 8은 **JDK 21**을 요구해서 JDK 21(Temurin 21.0.13, 체크섬 확인)을 사용자 폴더에 풀어 썼다. 설치 프로그램은 쓰지 않았다.
- 안드로이드 빌드 도구가 **한글 경로를 거부**해서, 빌드는 `C:\ipo-app-build`(한글 없는 경로)로 복사해서 한다.
- 이 작업 환경(Claude 도구)에서는 자바의 로컬 소켓이 막혀 Gradle이 시작되지 않았다. 빌드는 사용자 터미널 탭에서 실행했다.
- 컴파일 SDK는 Capacitor 기본값 36이다. Gradle이 SDK 플랫폼 36과 빌드 도구 35를 자동으로 받았다.
